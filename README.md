# Study Plan – Android app + widget

## Upload to GitHub (no folders needed)
1. github.com → **+ → New repository** → name `study-plan` → **Public** → **Create repository**.
2. Click **uploading an existing file**. Select ALL the files in this folder at once and drag them in
   (everything except `build.yml` is fine to include; including it does no harm). Click **Commit changes**.
3. Click **Add file → Create new file**. In the name box type exactly:
   `.github/workflows/build.yml`
   (typing the `/` creates the folders for you). Open `build.yml` from this folder, copy all of it,
   paste it into the big box, click **Commit changes**.
4. Open the **Actions** tab. "Build APK" runs by itself (~5 min) and turns green.
5. On your phone open the repo → **Releases** (right side) → **Study Plan (latest build)** → tap **StudyPlan.apk**.

## Install
Open StudyPlan.apk. Allow "Install unknown apps" if asked. If Play Protect warns, tap **More details → Install anyway**.

## Widget
Long-press the home screen → **Widgets** → **Study Plan** → drag it onto the screen.
